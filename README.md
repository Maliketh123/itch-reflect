# itch-reflect

A NASDAQ ITCH 5.0 market-data decoder written twice: once by hand, once generated by
C++26 reflection, with measurements comparing the two.

## Stages

| Stage | What you build | C++ you learn | Compiler |
|---|---|---|---|
| 1 | Read big-endian integers from raw bytes | bytes, fixed-width integers, pointers, bit shifts, header files, CMake | any (GCC 11+) |
| 2 | Hand-written decoder for the Add Order message, then the other order-book messages | structs, `std::span`, `switch`, reading a binary file | any |
| 3 | Benchmark: messages per second and per-message latency (p50, p99) on a NASDAQ sample file | `std::chrono`, optimisation flags, how to measure honestly | any |
| 4 | Templates warm-up: one generic `read<T>` instead of four functions | templates, `constexpr`, concepts | any |
| 5 | Reflection decoder: describe a message as a plain struct, generate the parser | `^^T`, `std::meta`, expansion statements | GCC 16.1+ with `-std=c++26 -freflection` |
| 6 | Compare stage 2 and stage 5: speed, generated assembly, lines of code. Write it up | Compiler Explorer, reading assembly | GCC 16.1+ |

Stages 1 to 4 need no new compiler. Do them first.

## Stage 1: read big-endian integers

Exchange feeds send numbers most-significant byte first ("big-endian"). Your PC stores them
least-significant byte first. So the bytes `00 00 01 F4` on the wire mean 0x000001F4 = 500.

Open `src/bytes.hpp` and fill in the four functions. Then build and run the tests:

    cmake -S . -B build
    cmake --build build
    ./build/test_bytes

You are done with stage 1 when it prints `all tests passed`.

Hints:
- `p[0]` is the first byte. For two bytes the value is `p[0] * 256 + p[1]`, usually written `(p[0] << 8) | p[1]`.
- Convert each byte to the result type before shifting it, e.g. `std::uint64_t(p[0]) << 40`.
  Shifting a small integer type too far is a classic bug.
- ITCH timestamps are 6 bytes (nanoseconds since midnight), which is why there is a 48-bit reader.

## Add Order message layout (used in stage 2)

| Offset | Bytes | Field |
|---|---|---|
| 0 | 1 | Message type, the letter `A` |
| 1 | 2 | Stock locate |
| 3 | 2 | Tracking number |
| 5 | 6 | Timestamp, nanoseconds since midnight |
| 11 | 8 | Order reference number |
| 19 | 1 | Buy/sell indicator, `B` or `S` |
| 20 | 4 | Shares |
| 24 | 8 | Stock symbol, padded with spaces |
| 32 | 4 | Price, in units of 1/10000 dollar |

Total: 36 bytes. Check this table against NASDAQ's official ITCH 5.0 specification before
relying on it.
